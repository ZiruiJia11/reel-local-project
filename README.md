# Reel Local Cinema SaaS

Reel Local Cinema SaaS is a full-stack cinema booking platform designed for independent cinemas, local film clubs, and community screening events.

This project is being rebuilt from an earlier academic prototype into a modern SaaS application using React, TypeScript, Node.js, PostgreSQL, Docker, and cloud deployment practices.

---

## Current Features

### Frontend

- React + TypeScript
- Vite
- React Router
- Responsive movie browsing experience
- Movie detail pages
- Protected routes
- Login and logout flow
- User profile page

### Booking

- Movie booking flow
- Schedule page
- Persistent storage using Local Storage

### Backend

- Node.js
- Express
- TypeScript
- Health Check API
- Movies API endpoint
