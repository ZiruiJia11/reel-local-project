# Reel Local Cinema SaaS

Reel Local Cinema SaaS is a full-stack cinema booking platform designed for independent cinemas, local film clubs, and community screening events.

This project is being rebuilt from an earlier academic prototype into a modern SaaS application using React, TypeScript, Node.js, Express, PostgreSQL, Prisma, and cloud deployment practices.

---

## Live Demo

Frontend:

https://reel-local-project.vercel.app

Backend API:

https://reel-local-project.onrender.com

Note: The backend is hosted on Render free tier and may take up to 50 seconds to respond after inactivity.
